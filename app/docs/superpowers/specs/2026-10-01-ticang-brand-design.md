# 题仓品牌升级设计规格

## 目标

将当前通用名称“错题集”升级为可用于中国应用市场、软件著作权和 APP 备案的正式品牌“题仓”。品牌首先服务大学生与考证人群，其次覆盖其他学习者，最后兼容中小学生及家长；第一印象应为专业、简洁、高效。

本次升级只调整品牌身份及与名称直接相关的技术标识，不重做产品结构、交互流程或已批准的视觉语言。

## 品牌系统

- 正式名称：题仓
- 软件著作权全称：题仓错题整理软件
- 软件著作权简称：题仓
- APP 备案服务名称：题仓
- 应用商店名称：题仓
- 宣传语：拍照归档，专注提分
- 商店简短介绍：拍照识别并归档错题，按科目与题型整理，随时乱序复习。
- 推荐商店分类：教育 / 学习工具；最终按各平台实际分类名称映射。

应用商店名称、安装后显示名称、软著简称和 APP 备案服务名称必须保持“题仓”完全一致，避免因字符、空格或名称差异导致审核失败。

## 视觉设计

保留已批准的图标结构和色彩：

- 背景：纯深蓝 `#07163E`
- 相机：亮蓝 `#2B6CF0`
- 镜头：黄色 `#F9D84A`，内圈使用背景深蓝
- 文字：相机下方使用白色粗体“题仓”

图标仍只保留相机和名称两个识别层级，不增加英文、副标题、渐变、纹理、闪光灯或装饰线。矢量母版中的名称改为“题仓”，建议字号 `168`、字重 `800`、字间距 `12`、基线 `y=858`；生成后以 Android adaptive icon 安全区域和 48 px 桌面尺寸实测为最终校准依据。

应用首页标题改为“题仓”，首页说明改为“拍照归档错题，按目标与科目整理，高效复习”。其他页面可以继续把“错题集”作为通用功能名使用，但不得再把它当作品牌或产品名。

## 技术标识

应用尚未在任何商店发布，因此在首次正式发布前同步更换包名，避免永久保留旧品牌拼音：

- Android application ID / namespace：`com.nanen9396.ticang`
- Capacitor app ID：`com.nanen9396.ticang`
- iOS bundle identifier：`com.nanen9396.ticang`
- Android Java 包路径：`com/nanen9396/ticang`
- 自定义 URL scheme：`com.nanen9396.ticang`

现有上传签名密钥继续使用。密钥证书中的旧内部名称不面向用户，也不影响新包名签名；重新生成密钥只会增加遗失和版本升级风险。

GitHub 仓库名称和本地目录暂不改名。它们不属于商店审核信息，等首次上架完成后再决定是否迁移，避免把品牌升级扩大成无关的仓库搬迁。

## 备份兼容

新导出的备份文件使用 `ticang-YYYY-MM-DD.ticang.json`，文档格式标识使用 `ticang`。导入器同时接受旧的 `cuotiji` 和新的 `ticang` 格式标识，确保现有测试数据和用户已有备份仍可恢复。

界面中的备份标题统一改为“题仓完整备份”。旧格式只作为兼容输入保留，不继续生成。

## 修改范围

实施阶段应覆盖以下位置：

- Web 页面标题、首页品牌标题、备份分享文案
- Capacitor 应用名称和 app ID
- Android namespace、application ID、Java 包路径、资源字符串和 URL scheme
- iOS bundle identifier 与显示名称
- 图标 SVG 母版及 Android、iOS 派生资源
- 名称、包名、图标、备份格式相关自动化测试
- `AGENTS.md` 中长期有效的品牌方向

不得改变错题数据模型、OCR 流程、复习逻辑、分类逻辑、签名密钥或现有页面布局。

## 验证标准

实施完成后必须满足：

1. Android 与 iOS 安装名称均为“题仓”，应用内首页品牌标题为“题仓”。
2. Android、iOS 和 Capacitor 的包标识统一为 `com.nanen9396.ticang`。
3. 新图标保留原配色和相机主体，“题仓”在 adaptive icon 安全区域及 48 px 尺寸下清晰、无遮挡。
4. 新备份按 `ticang` 格式导出，旧 `cuotiji` 备份仍能导入。
5. 运行时完整性、类型检查、构建、模型、备份、OCR、原型、图标、原生与 Android 发布测试全部通过。
6. 重新生成并验证签名 APK 和 AAB；签名证书指纹必须与现有上传证书一致。
7. Git 差异中不得包含密钥、口令、付款资料或个人身份材料。

## 非目标

- 不增加 AI 解题、云同步、账号、订阅或支付功能。
- 不重新设计应用页面或更改已经批准的配色。
- 不申请商标、软著或 APP 备案；这些属于品牌落地后的外部流程。
- 不承诺“题仓”商标一定可注册。公开搜索只能排除明显重名，正式申请前仍需通过国家知识产权局和版权登记渠道核验。
