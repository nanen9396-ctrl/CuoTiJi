## 交付的是什么

本地优先的 Android 错题整理候选项目：照片 / 相册、印刷中英文 OCR、自定义分类、搜索编辑、顺序 / 乱序复习、含原图完整备份。技术为 React、TypeScript、Capacitor、IndexedDB；没有业务服务端、账号、云同步、支付或订阅。

买方得到约定范围的代码、构建资料和支持，不是现成用户、流量、应用市场账号、商标注册结果或确定盈利。功能与未验收项见 [Android 交付说明](android-delivery.md)。

## 普通交付包必须排除

- 密钥与凭据：`*.jks`、`*.keystore`、`keystore.properties`、`.env*`、`*.p12`、`*.pfx`、`*.key`、`AuthKey_*.p8`、`*.mobileprovision`；PEM 默认排除，明确需要的公开证书另列白名单。
- 身份、财务和账号资料：身份证、住址、联系方式私密记录、付款资料、商店账号、会话 Cookie、令牌、API 密钥。
- 用户数据：真实题干、笔记、照片、`.ticang.json` / `.cuotiji.json`、截图、设备标识、ADB/UI dump 和私人日志。
- 本机状态：`local.properties`、`.git/`、`.worktrees/`、`.browser/`、`.codex/`、`.agents/`、`.superpowers/`、IDE 用户设置、`xcuserdata/`。
- 缓存 / 调试输出：`node_modules/`、`.pnpm-store/`、`.gradle/`、`build/`、`dist/`、`DerivedData/`、`test-results/`、`playwright-report/`、`captures/`、浏览器 profile / storageState。
- 生成的 `public/ocr/` 不直接混入源码副本；构建脚本重建它，实际安装包必须含 OCR 资源及许可，不能把 Git 忽略误作允许删掉分发声明。

Git 忽略不等于交付安全检查通过。不为打包删除源工作区文件；现有真实发行密钥不能作为通用源码商品附赠。接手已发布应用必须另行明确签名连续性与安全交接，不能简单换钥。

## 权属核查工作单

1. **业务与模板**：核实原创代码、受保护手机模拟运行时、系统外观图像各自的允许用途；[app/AGENTS.md](../../app/AGENTS.md) 的编辑边界及 runtime hash 校验不等于商业授权。
2. **OCR**：保留 [OCR NOTICE](../../app/resources/ocr-NOTICE.md) 及完整许可；worker 传递依赖、compiled core 的 Leptonica / 编解码器等仍需完整核查，部分声明不等于全部闭合。
3. **字体与依赖**：覆盖锁定的直接和传递依赖、Android / iOS 原生依赖及实际随包资源，不能只看 package.json 的 license 字段。
4. **图标与品牌**：确认生成来源、使用范围和品牌可用性，不保证商标可注册。
5. **题目与图片**：演示只用自编或授权素材；不附用户错题库，不声称拥有教材、真题或试卷转售权。

由权利人、交易双方及必要的专业审核确认；本说明不直接授予任何许可或替代法律意见。

## 买方验收与支持怎么约定

- 可重建：在约定环境按锁文件安装，检查、类型检查和构建成功；首次依赖下载需要网络与相应许可确认。
- 可追溯：实际记录提交号、包大小、SHA256、签名身份、检查人员与时间。
- 功能：自编题目验证录入、分类、修改、重启、复习和备份；不扩大到手写、公式或 AI 解题。
- 数据：隔离环境核对文字、分类、非空答案笔记、原图、重复 ID 和失败回滚，不破坏唯一用户数据。
- 缺口：书面接受暂缓项或约定补齐后验收，不把自动检查替代真机检查。
- 支持：约定时长、环境数量、答疑渠道、缺陷与新增需求界限；云端、支付、AI 服务另立范围。
