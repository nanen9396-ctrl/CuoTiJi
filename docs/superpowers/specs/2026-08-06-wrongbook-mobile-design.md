# 错题集手机 App 设计说明

## 目标

让学生用最短路径把纸面错题变成可分类、可检索、可重复练习的个人题库。

## 核心流程

1. 用户从首页拍照或选择题目图片。
2. App 模拟识别题目文字与图片区域。
3. 用户确认或修正科目、题型、正确答案和笔记。
4. 题目保存到对应科目题库。
5. 用户从题库选择顺序或乱序复习，并按需显示答案。

## 原型架构

- React + TypeScript + Vite 单页应用。
- `Prototype.tsx` 管理原型页面状态与交互流程。
- `wrongbook-model.ts` 提供科目分组和无副作用乱序逻辑。
- 当前数据存于前端内存，仅用于验证流程；刷新后恢复示例数据。
- Playwright 覆盖从首页、识别、保存到乱序复习的主路径。

## 数据草模

每道错题至少包含：题目 ID、科目、题型、题干、正确答案、个人笔记和创建时间。后续接入持久化时可在此基础上增加原图地址、OCR 置信度、掌握度与复习记录。

## 本阶段不做

- 真实 OCR 与图像区域识别
- 用户账号、跨设备同步和云存储
- 复习算法、提醒和学习统计
- 后台管理与内容审核

这些能力在交互流程确认后分阶段实现，避免在产品方向未定时引入不必要的后端复杂度。
